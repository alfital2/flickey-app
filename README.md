# FlicKey website

**Looking for the app? [Download the latest FlicKey release](https://github.com/alfital2/FlicKey/releases/latest).**

The [FlicKey repository](https://github.com/alfital2/FlicKey) is the single source of truth for app source code, releases, release notes, and issues.

- [Download FlicKey for macOS](https://github.com/alfital2/FlicKey/releases/latest/download/FlicKey.dmg)
- [All releases and release notes](https://github.com/alfital2/FlicKey/releases)
- [Source code and build instructions](https://github.com/alfital2/FlicKey)
- [Report an issue](https://github.com/alfital2/FlicKey/issues)

This repository hosts [flickey.site](https://flickey.site) and its [Sparkle update feed](https://flickey.site/appcast.xml) through GitHub Pages. App releases are published only in `alfital2/FlicKey`; historical app releases here are no longer maintained. Use the links above for the current app.

For future app releases, publish the signed app assets in `alfital2/FlicKey`, then update `appcast.xml` here to reference that release's ZIP, version, build, signature, and byte length. Keep website download links pointed at the main repository's latest release.
